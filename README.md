# House Price Prediction

A regression project for predicting house prices from property characteristics.

## Pipeline
1. Load dataset
2. Exploratory data analysis
3. Missing-value treatment
4. Feature encoding
5. Random Forest regression
6. MAE, RMSE and R2 evaluation

## Technologies
Python, Pandas, NumPy, Scikit-learn, Matplotlib
